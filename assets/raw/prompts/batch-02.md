# Prompt batch 02: Yoav as an Israeli commando

Session 2. Ran's direction: the squad must read as Israeli soldiers, in green.
Ran shared five real photos as mood references. Per CLAUDE.md they are not attached
to any prompt; the kit is described in words instead.

Kit taken from the references (mood only):
- Solid olive drab combat uniform, top and trousers the same olive. Knee pads.
- High-cut ballistic helmet in olive, night vision mount, often a monocular folded up, comms headset.
- Balaclava or face wrap in olive, clear shooting glasses.
- Slim olive plate carrier, magazine pouches, a radio with an antenna on the back.
- Coyote tan accents: gloves, some pouches, compact bullpup carbine.
- Thigh pistol holster, tan boots.

Readability rule from the Session 2 test: one light value per figure (the tan accents), so the
operator separates from the blue night ground at 44 px.

Not included: flags, unit patches, insignia, readable text. The unit is fictional.

Settings in Flow: Nano Banana 2.1, 16:9, x4, no attachment.
