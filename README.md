# Launch Window

An isometric stealth-tactics game for the browser, in the style of Commandos 1.
Three Israeli commandos sabotage missile launchers at a fictional base before the launch countdown ends.

- **Play the prototype:** open `prototype/launch-window.html` in a browser.
- **Plan:** `PLAN.md`
- **Rules for Claude Code:** `CLAUDE.md`
- **Start Session 1:** paste the prompt in `KICKOFF.md` into Claude Code.

All art, maps and names are original.
